import os from weasyprint import HTML html_content = """ Planificación del Proyecto: App Móvil de Control de Gastos

App Personal de Control de Gastos por Chat

Documento de Arquitectura, Flujo y Estructura del Sistema

1. Visión General del Sistema

El proyecto consiste en una aplicación móvil de uso estrictamente personal que permite registrar gastos diarios escribiendo un mensaje en lenguaje natural dentro de una interfaz de chat. Un backend auto-alojado en una notebook doméstica procesa los mensajes con Inteligencia Artificial, registra los datos y genera análisis visuales.

2. Componentes de la Arquitectura

Cliente Móvil (Frontend)

  • Tecnología: React Native (Expo) o Flutter.
  • Pantallas principales: Interfaz de Chat (registro) y Dashboard (gráficos y reportes).

Servidor Doméstico (Backend)

  • Alojamiento: Notebook siempre encendida conectada a la red local.
  • Tecnología API: Node.js (Express) o Python (FastAPI).
  • Procesamiento IA: API de Gemini para la extracción estructurada de entidades (monto, concepto, categoría).
  • Acceso Remoto Seguro: Cloudflare Tunnel o VPN privada (Tailscale) para conectar el teléfono fuera de casa.

Base de Datos

  • Motor: SQLite (base de datos relacional ligera en archivo único) o PostgreSQL.

3. Diseño de la Base de Datos

Tabla Campo Tipo Descripción
gastos id INTEGER PRIMARY KEY Identificador único del gasto
gastos monto REAL / DECIMAL Valor numérico del gasto
gastos descripcion TEXT Detalle extraído del mensaje (ej. Nafta YPF)
gastos categoria_id INTEGER (FK) Relación con la tabla de categorías
gastos fecha DATETIME Fecha y hora del registro
categorias id INTEGER PRIMARY KEY Identificador único de la categoría
categorias nombre TEXT Nombre (ej. Alimentación, Transporte, Servicios)
categorias color_hex TEXT Código de color para gráficos (ej. #3182ce)

4. Flujo de Datos y Registro

  1. El usuario ingresa un texto en la app móvil: "Pagué 4200 de supermercado".
  2. La app envía el texto al backend local vía solicitud HTTPS.
  3. El backend consulta la API de Gemini enviando un prompt con salida formateada en JSON.
  4. Gemini devuelve: {"monto": 4200, "categoria": "Alimentación", "descripcion": "Supermercado"}.
  5. El backend guarda la fila correspondiente en SQLite.
  6. Se devuelve una respuesta al chat confirmando el registro del gasto.

5. Visualización y Estadísticas

La vista de estadísticas consultará directamente la base de datos para generar:

  • Gráfico de Torta / Dona: Distribución porcentual de gastos por categoría en el mes seleccionado.
  • Gráfico de Barras: Evolución diaria o semanal de gastos para detectar picos de consumo.
  • Listado Histórico: Filtro por fechas con opción de eliminar o editar registros.
